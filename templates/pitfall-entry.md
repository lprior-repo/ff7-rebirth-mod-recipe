# Pitfall entry template (append to docs/16)

Copy, fill, and add under the right section. Confidence code: **C** = confirmed by a discriminating observation; **L** = likely; **U** = unknown cause. Never state a cause you did not test as confirmed.

```
### P<next number> — <short name>  (<C|L|U>)
* **Scope:** game build <id>, editor <version>, Blender <version>, Proton <version>, host/compositor <details>.
* **Symptom:** <what was seen, with the exact message or screenshot description>.
* **Cause:** <proven cause, or "[INFERENCE: ...] what would prove it">.
* **Fix / workaround:** <what resolved it, and whether the fix was verified>.
* **Guard:** <the check that would have caught this earlier — a gate, assertion, or checklist line>.
* **Evidence:** <report names/screenshot labels kept privately>.
```
