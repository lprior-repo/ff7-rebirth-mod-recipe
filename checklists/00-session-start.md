# 00 — Session start (new or resumed project)

- [ ] Read the project's agent rules, README, status file, and the specific current report the status file names. (Old work-logs = evidence only.)
- [ ] State card written: current candidate / installed candidate / historical + rejected candidates.
- [ ] Gate table copied from the ledger: each gate `PASS/FAIL/NOT_RUN` with report path + input hash.
- [ ] Human approvals listed verbatim with date and bound hash; "not approved" scope noted.
- [ ] Contradictions between documents found and resolved (latest dated owner decision wins); unresolved ones queued as questions.
- [ ] Do-not-repeat list extracted from project docs.
- [ ] Fresh read-only inventory taken **this session** (build id, game exe hash, installed mod files, processes, launch options). Differences from ledger recorded.
- [ ] Game process state checked (running? closed?). Not assumed.
- [ ] Host services the project may have stopped checked (running/stopped); restoration state known.
- [ ] Disk headroom checked for the planned stage.
- [ ] Task classified with the table in [docs/18 §2](../docs/18-continuing-an-existing-mod.md); cheapest correct entry stage chosen.
- [ ] Questions that need the human batched into **one** message (art, launch permission, service stop, account steps).
- [ ] Output directory names for this session decided (fresh, immutable).
